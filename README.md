# ChichiBooVibe

교육·뮤지컬·디지털 융합 수업을 위한 웹앱 포트폴리오/허브입니다.  
여러 개의 교육용 웹앱을 한 곳에서 **탐색·검색·분류·소개**할 수 있도록 구성되어 있습니다.

---

## 앱의 목적

ChichiBooVibe는 다음 목적을 위해 만들어졌습니다.

- 교육 현장에서 바로 활용 가능한 웹앱을 카테고리별로 정리
- 뮤지컬 기반 창작 수업과 디지털 시민교육을 연결하는 실천 사례 공유
- 교사/학습자가 필요한 도구를 빠르게 찾을 수 있도록 검색성과 가독성 강화
- 교육적 아이디어를 기록하고, 확장 가능한 아카이브 형태로 운영

---

## 앱 구조

**데이터와 화면이 분리된 정적 사이트**입니다.

- `data/apps.json` ← **콘텐츠를 추가·수정·삭제할 때 여기만 편집합니다**
  - `categories` : 카테고리 목록(이름, 이모지, 소개 문구, 색상)
  - `apps` : 앱 목록(이름, 카테고리, 설명, 태그, 이미지 등)
- `index.html`
  - UI 레이아웃(히어로, 소개, 컬렉션, 컨셉)
  - Tailwind CDN 기반 스타일링 + 일부 커스텀 CSS
  - `data/apps.json`을 불러와 카드·필터·컨셉 섹션을 렌더링하는 스크립트
- `README.md`
  - 프로젝트 목적/구조/운영 가이드 문서

앱 개수, 카테고리별 개수, 필터 버튼, 컨셉 섹션은 모두 `data/apps.json`에서 자동으로 계산됩니다.
별도 빌드 도구 없이 동작하는 정적 웹앱 아카이브입니다.

> **로컬에서 확인할 때**: 브라우저 보안 정책상 `index.html`을 파일로 직접 열면 데이터를 읽지 못합니다.
> 프로젝트 폴더에서 `npx serve` 또는 `python3 -m http.server` 로 실행한 뒤 접속해 주세요.
> (GitHub Pages에 올라간 실제 사이트는 그냥 정상 동작합니다.)

## 앱 추가·수정·삭제 방법

`data/apps.json`의 `apps` 배열만 편집하면 됩니다. **`index.html`은 건드리지 않습니다.**

### 앱 추가

`apps` 배열 끝에 아래 형태로 항목을 추가합니다. (앞 항목 끝에 쉼표 `,`를 빠뜨리지 않도록 주의)

```json
{
  "title": "핑거피플",
  "engTitle": "Finger People",
  "category": "인문·창작",
  "description": "손가락을 한 명의 인물로 상상해 설정과 그림을 만들고 인물 카드로 완성하는 창작 웹앱",
  "tags": "#인물창작 #예술치료 #캐릭터",
  "imageUrl": "https://drive.google.com/thumbnail?id=파일ID&sz=w2000",
  "siteUrl": "https://chichiboo.link/example",
  "youtubeVideoId": "abcdefghijk"
}
```

| 항목 | 필수 | 설명 |
| --- | :---: | --- |
| `title` | ✅ | 앱 이름(국문) |
| `engTitle` | ✅ | 앱 이름(영문) |
| `category` | ✅ | 아래 카테고리 중 하나와 **정확히 일치**해야 합니다 |
| `description` | ✅ | 한 줄 설명 |
| `tags` | ✅ | `#태그` 를 **띄어쓰기로 구분**한 하나의 문자열 |
| `imageUrl` | | 썸네일 이미지 직접 링크 (없으면 기본 아이콘 표시) |
| `siteUrl` | | 앱 주소. 넣으면 카드에 `링크` 배지가 붙습니다 |
| `youtubeVideoId` | | 유튜브 영상 ID. 넣으면 카드에 `영상` 배지가 붙습니다 |

- **id 번호는 없습니다.** 순서대로 자동 처리되므로 번호를 직접 매길 필요가 없습니다.
- **수정**은 해당 항목의 값을 고치면 되고, **삭제**는 항목 전체(`{ … }`와 뒤 쉼표)를 지우면 됩니다.
- 카드가 보이는 순서는 `apps` 배열에 적힌 순서를 따릅니다. (전체 보기에서는 카테고리 순으로 묶여 표시)

### 카테고리 추가

`categories` 배열에 한 항목만 추가하면 필터 버튼과 Concept 섹션이 함께 갱신됩니다.

```json
{
  "name": "새 카테고리",
  "emoji": "🌟",
  "tagline": "Concept 섹션에 표시할 한 줄 소개",
  "gradient": "from-lime-400 to-green-600",
  "text": "text-lime-500"
}
```

`gradient`와 `text`는 Tailwind 색상 클래스명을 그대로 사용합니다.

### 잘 안 될 때

편집 후 사이트에서 브라우저 개발자 도구 콘솔(F12)을 확인하세요.

- 카테고리명 오타나 필수 항목 누락은 **경고 메시지로 알려주고, 나머지는 정상 표시**됩니다.
- 쉼표·따옴표 실수로 JSON이 깨지면 화면에 "앱 목록을 불러오지 못했습니다" 안내가 뜹니다.
  GitHub 웹에서 `data/apps.json`을 열면 문법 오류 위치를 표시해 주니 그걸 보고 고치면 됩니다.

## 개인정보/보안 관련 운영 원칙

이 저장소 문서와 앱 소개에는 다음 원칙을 적용합니다.

- 개인 연락처, 주소, 계정 정보 등 **민감한 개인정보는 최소한으로만 기재**
- 외부 링크는 공개 가능한 공식 채널 위주로만 사용
- API Key, 비밀번호, 토큰 등 비공개 정보는 저장소에 절대 포함하지 않음
- 이미지/콘텐츠 업로드 시 개인정보가 포함되지 않았는지 사전 확인
