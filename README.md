# ChichiBooVibe 자료 추가 가이드

이 사이트는 `index.html` 하나에 모든 앱 데이터가 담겨 있습니다.
새 자료를 추가할 때는 아래 정보를 알려주세요.

---

## 새 앱 추가 요청 형식

```
앱 이름:       (한국어)
영문 이름:     (영어)
카테고리:      (아래 5개 중 하나)
설명:          (한 줄 기능 설명)
태그:          #태그1 #태그2 #태그3
이미지 URL:    https://i.ibb.co/…/screenshot.png
유튜브 ID:     (선택, 없으면 생략)
```

### 예시

```
앱 이름:       뮤지컬 대본노트
영문 이름:     Musical Script Note
카테고리:      뮤지컬
설명:          뮤지컬 최적화 대본 작성·관리 도구
태그:          #대본 #가사 #시나리오
이미지 URL:    https://i.ibb.co/RTShng0m/image04.png
유튜브 ID:     mRlLQR86f30
```

---

## 카테고리 목록 (5개)

| 카테고리 | 설명 |
|----------|------|
| `뮤지컬` | 뮤지컬 교육 관련 도구 |
| `인문·창작` | 시·이야기 창작, 독서 토론 등 |
| `인터랙티브 시각디자인` | 움직임·AR·사진 기반 디자인 도구 |
| `디지털·세계시민교육` | SDGs, 출처 표기 등 |
| `수업디자인` | 수업 계획·커리큘럼 설계 도구 |

---

## 이미지 업로드 방법

1. [https://imgbb.com](https://imgbb.com) 접속
2. 스크린샷 이미지 업로드
3. 업로드 완료 후 **"Direct link"** 복사 (`.png` / `.jpg` / `.webp`로 끝나는 URL)
4. 위 형식의 `이미지 URL:` 항목에 붙여넣기

---

## 유튜브 영상 ID 찾는 법

유튜브 영상 URL에서 `v=` 뒤의 값만 입력합니다.

```
https://www.youtube.com/watch?v=mRlLQR86f30
                                ↑ 이 부분만 입력: mRlLQR86f30
```

---

## 데이터 필드 설명

| 필드 | 필수 | 설명 |
|------|------|------|
| `id` | 자동 | 자동으로 부여 (마지막 번호 + 1) |
| `category` | 필수 | 위 카테고리 5개 중 하나 (정확히 일치해야 함) |
| `title` | 필수 | 한국어 앱 이름 |
| `engTitle` | 필수 | 영어 앱 이름 |
| `description` | 필수 | 한 줄 기능 설명 |
| `tags` | 필수 | `#태그` 형식, 공백으로 구분 |
| `imageUrl` | 필수 | 스크린샷 이미지 직접 링크 |
| `youtubeVideoId` | 선택 | 유튜브 영상 ID (없으면 생략) |
